# Definition of Ready / Definition of Done

## Definition of Ready

一个 Feature 进入开发前：

- [ ] Problem / Goal 明确
- [ ] User / Actor 明确
- [ ] Scope 明确
- [ ] Acceptance Criteria 可测试
- [ ] Dependencies 明确
- [ ] Data impact 已分析
- [ ] Permission impact 已分析
- [ ] Security impact 已分析
- [ ] UX states 明确
- [ ] NFR 已考虑
- [ ] Open Questions 不阻塞开发

## Definition of Done

一个 Feature 完成：

- [ ] Acceptance Criteria 全满足
- [ ] Code Review 完成
- [ ] lint / typecheck / build 通过
- [ ] Unit / Integration 按需通过
- [ ] Critical E2E 通过
- [ ] Permission / Tenant tests 通过
- [ ] Security issues resolved
- [ ] Migration validated
- [ ] Documentation updated
- [ ] Monitoring / Logs 按需添加
- [ ] Release Notes 按需更新
- [ ] Product Owner / 业务验收完成
