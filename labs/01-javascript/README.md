# Lab 01 — JavaScript

对应教材：
[JavaScript](../../docs/05-javascript.md)

## 运行环境

确认：

```bash
node -v
```

## 推荐顺序

```bash
node 01-basics.js
node 02-arrays.js
node 03-async.js
node exercises.js
```

最后才打开：
`solutions.js`

## 学习方法

每段代码运行前先猜：

1. 输出是什么？
2. 为什么？
3. 哪个变量发生变化？
4. 哪个操作返回新数组？
5. 哪个操作可能报错？

然后再运行。
