# Lab 00：HTML/CSS Dashboard

对应教材：

- docs/03-web-fundamentals.md
- docs/04-html-css.md

## 目标

不使用 React，只使用 HTML + CSS 完成一个 SaaS Dashboard。

必须掌握：

- semantic HTML
- form
- table
- box model
- flex
- grid
- responsive design
- accessibility basics

## 运行

直接打开：

`index.html`

## 任务

1. 阅读现有 HTML，指出 header/nav/main/table 的语义。
2. 使用 DevTools 查看每个 Card 的 Box Model。
3. 把三列 KPI 改成四列。
4. 在 800px 以下变成单列。
5. 为 Project Table 增加 Priority 列。
6. 为 Search Input 增加 label。
7. 不使用 `!important`。

## 验收

你应能解释：

- 为什么 button 不应该用 div 模拟
- margin 与 padding 区别
- flex 与 grid 区别
- 为什么 Client Validation 不能替代 Server Validation
