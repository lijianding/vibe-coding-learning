# Lab 02 — TypeScript

对应：
[TypeScript](../../docs/06-typescript.md)

## 安装

```bash
cd labs/02-typescript
npm install
```

## 类型检查

```bash
npm run check
```

## 运行示例

```bash
npm run start
```

## 做练习

```bash
npm run exercise
```

完成后才看：

```bash
npm run solution
```

## 重点观察

故意制造类型错误，再执行：

```bash
npm run check
```

理解 TypeScript 是如何在“运行前”发现问题的。
